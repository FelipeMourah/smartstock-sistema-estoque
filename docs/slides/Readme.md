# SmartStock

Sistema inteligente de gestão de estoque com automação e visão computacional.

## Objetivo
Desenvolver uma plataforma web para gerenciamento de estoque adaptável a diferentes tipos de estabelecimentos.

## Tecnologias
- Python
- FastAPI
- HTML/CSS
- OpenCV (futuro)
- APIs de pagamento

## Estrutura
- docs → documentação acadêmica
- prototipo → telas e layouts
- backend → API do sistema
- frontend → interface web
